DHARTIVA Static Website
========================

Files:
- index.html       Home page
- products.html    Product page
- about.html       About page
- contact.html     Contact page
- css/style.css    Responsive styling
- js/script.js     Mobile menu + demo contact form
- images/          DHARTIVA logo, hero image and product images

How to run:
1. Extract the ZIP.
2. Double-click index.html, or open it in a browser.
3. For Laravel later, move the images into public/images, CSS into public/css, JS into public/js,
   and convert the HTML files into Blade files under resources/views.

The contact form is static/demo only. It does not send email until connected to a backend.
